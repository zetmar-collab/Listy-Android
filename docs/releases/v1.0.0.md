# Studio playlist — Android 1.0.0

Pierwsze wydanie Android / First Android release.

- Albumy i podkatalogi; playlisty nazwane jak foldery / Album and subfolder playlists named after folders.
- M3U8, M3U, PLS, XSPF, WPL; wybór formatów audio / Five playlist formats and selectable audio extensions.
- Ręczny edytor, podgląd, cofanie, zmiana nazw i usuwanie playlist / Manual editor, preview, undo, rename and deletion.
- Kopie `.bak`, numerowane wersje, kontrola duplikatów i brakujących plików, naprawa ścieżek / Backups, numbered versions, duplicate/missing checks and path repair.
- Interfejs PL/EN; lokalne działanie bez konta i reklam / Polish/English UI; local operation without accounts or advertising.

**Android 8.0+ (API 26).** APK podpisany dewelopersko do instalacji testowej / Development-signed installation/test APK. Nie wymaga środowiska .NET / No .NET runtime required.

Pobierz APK oraz `SHA256SUMS.txt`. Dla najlepszej zgodności z odtwarzaczami zapisuj listy w folderze muzycznym ze ścieżkami względnymi. / Download the APK and `SHA256SUMS.txt`. For best player compatibility, save playlists inside the music folder with relative paths.

Weryfikacja / Validation: 21 JVM tests and 8 instrumented emulator tests passed; Android Lint passed without errors. APK Signature Scheme v2 verified. Test reports cover the local build; physical devices and third-party cloud document providers may differ.
